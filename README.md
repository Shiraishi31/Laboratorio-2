# Laboratorio #2 - Clases en C#

Este repositorio contiene el desarrollo del Laboratorio #2 de la materia Herramientas de Programación Aplicada III (.NET).

El laboratorio está enfocado en el uso de clases, objetos, métodos, parámetros, variables de instancia y propiedades en C#.

## Actividades realizadas

- Actividad 1: Creación de la clase `LibroCalificaciones` y uso del método `MostrarMensaje()`.
- Actividad 2: Uso de un método con parámetro para mostrar el nombre de un curso.
- Actividad 3: Uso de variables de instancia, propiedades `get` y `set`, y constructor.

Los programas fueron realizados como aplicaciones de consola en C# utilizando Visual Studio.
